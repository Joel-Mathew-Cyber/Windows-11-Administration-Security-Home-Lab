Project Status: In Progress

Objective

This project aims to develop practical skills in Windows 11 administration and security through hands-on experimentation in a controlled virtual environment. The focus is on understanding Windows operating system functionality, managing system configurations, exploring built-in security features, and practicing fundamental IT administration tasks.
